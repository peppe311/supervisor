# Community code of conduct

Treat contributors and users with respect. Critique the code and ideas, explain
your reasoning and allow room for different backgrounds and experience levels.

Harassment, threats, discriminatory abuse, sexual harassment, doxxing, spam and
deliberate exposure of private information are not acceptable in issues, pull
requests, discussions or other project spaces. Do not post private conversations
or account information without permission.

Maintainers may edit or remove harmful content, lock a discussion, ask someone
to change their behavior or restrict participation. Decisions should be
proportionate to the conduct and protect affected people.

To report a conduct issue, contact the repository maintainer through an available
private channel on their GitHub profile. If none is listed, open an issue asking
for a private channel without describing the incident or naming affected people.
Do not use security advisories for ordinary conduct disputes.
