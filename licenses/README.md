# Dependency notices

`dependencies.json` and the root `THIRD_PARTY_NOTICES.md` are generated by
`scripts/update-licenses.ps1`. They include versioned metadata and deduplicated
license/notice texts, not dependency source snapshots.

`upstream.json` records immutable upstream URLs, local text files and SHA-256
digests for license notices missing from published package archives. These
fallbacks are version-specific. Never change a package version without reviewing
its notices. Some upstream packages declare a standard license but omit the
text; `standard-notices.txt` explains the attribution and reproduces that text.

The Windows x64 dependency set and installed frontend build dependencies must
have notices. Other Cargo targets are inventoried but are not distribution
targets; gaps there are explicitly recorded. Optional npm binaries for other
systems are not installed, bundled or claimed as verified by this Windows check.
