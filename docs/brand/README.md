# Brand deliverables

Canonical Supervisor artwork, outlined wordmark, PNG icons and native icon files
are maintained in `assets/`. See [the brand contract](../SUPERVISOR_BRAND.md).
Shared colors and typography remain defined in `assets/themes.css`.

The original design-delivery ZIP is retained in the maintainer's local project
and excluded from the public source export. It is not needed to build the app.
Third-party icons and fonts retain the licenses documented in `LICENSES.md`.
