Supervisor requests SF Pro Text and SF Pro Display when the operating system
provides them. Its Windows package embeds this Inter subset as the
metrically similar licensed fallback. No external font request or system
installation is required. The approved Supervisor wordmark remains outlined
SVG; commands, code and terminal output retain the existing monospace stack.
