# Manrope variable font

Unmodified Google Fonts OFL release, retrieved 2026-09-10.
This is the open-source release, not the separately licensed current Manrope V5.

- Source: https://github.com/google/fonts/tree/main/ofl/manrope
- Original filename: `Manrope[wght].ttf`
- Download: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf
- Source project commit recorded by Google Fonts: `6f81ebecdf65e4463b798cc07b16a4f8d5216917`.
- Weight axis: 200–800; normal style. Browser-generated oblique remains available for emphasized prose.
- Coverage declared by the source: Latin, Latin extended, Cyrillic, Cyrillic extended, Greek, Vietnamese.
- Size: 165420 bytes.
- SHA-256: `d0639be45d0af36e798172419d7bd173c4bd4f29e2b76cbb69db1d11bf8b0a40`.
- License: SIL Open Font License 1.1, reproduced in `OFL.txt` and the packaged third-party notices.

The internal hosts load the font as a native-injected data URL from
`assets/themes.css`. No external font request or system installation is required.
The approved Supervisor wordmark remains outlined SVG; monospace output retains
its existing system stack.
